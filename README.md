# GT IPTV Player Pro 1.9.8-r0

- **Favorites** now displays a 4×3 grid of cards with a narrower details panel on the right.
- Overflowing text on the selected row or card starts scrolling after **1.5 seconds** and stops when the selection changes.
- Improved stability at startup and when pressing **EXIT**. The account list now shows a warning if the automatic **Xtream** or **Stalker** account test fails to start.

**mHub v2 sources**

Users add their own mHub v2 source URLs. The selected source supplies the streams, and GT IPTV Player Pro plays them directly on the receiver.

**HD Satelit compatibility note**

On the tested HD Satelit image, category names may appear blank on the Movies screen. The issue was reported to the HD Satelit team.
