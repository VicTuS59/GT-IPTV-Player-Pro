## R96 transparent dashboard panels

The seven menu panels now have no fill. Their sharp blue-magenta backdrop is
reused from `global-neon-v0912.png`, darkened uniformly only within the existing
left-rail boundary; the rest of `dashboard-neon-v0912.png` remains pixel-identical.
The result is remapped to the original 255-colour indexed palette and stripped
to mandatory PNG chunks so older Enigma2 image decoders load it reliably. The
rounded outlines and runtime selection geometry remain unchanged. The new asset
is also installed as a byte-identical regular file under the R95 name so stale
upgrade bytecode cannot blank the dashboard. No image generation or compositing
runs on the receiver.

- `dashboard-menu-overlay-r96.svg`:
  `e6ec48e51f25007f24b9144ae799a8a31ff6ff54c7aa09d80a99a9b6a0d3a944`
- `generate-dashboard-r96.sh`:
  `a3d09f55fd2572f6657f282ccde61a973d0689f2be310dee12ad4aaef3bdf9ea`

## R88 archive hero and R97 receiver optimization

The text-free neon clock artwork was generated with OpenAI ImageGen on
2026-09-08 for the project owner's approved TV Archive design, then revised
for R88 with a smaller clock and rewind arrow to keep the full motif inside
the dashboard card. Labels are
rendered by the interface and remain translatable. R97 derives the distributed
asset from the reviewed 2172x724 R88 master (`c89520b8488bda2bc448029f1a72d7802bafd897dd24bf01440ff01c6d573cc4`),
resizing it to the exact 1374x458 maximum dashboard decode and encoding it as a
stripped 255-colour indexed PNG. The stable runtime filename avoids another
upgrade path transition; the original master remains recoverable from R96 git
history rather than being duplicated in the receiver package.

## R108 cinematic mask

`cinematic-scrim-r108.png` is original project artwork generated for R108.
It is a deterministic 16 × 16 uniform RGBA mask containing no text, font,
metadata or third-party material. Enigma2 scales and alpha-blends it over an
already opaque cinematic backdrop so the hardware DVB video plane cannot show
through the OSD.
